# Educational Platform API

Backend API for an educational platform designed to make high-quality learning resources accessible to students regardless of their location.

The project started as a learning exercise to deepen my understanding of backend engineering and is gradually evolving into a platform concept that could support educational videos, structured courses, discussions, and learning progress tracking.

## Features

Current features:
- User registration
- User authentication
- PostgreSQL integration
- REST API built with FastAPI

Planned features:
- JWT authentication
- Courses, modules, and videos
- Discussion system
- Learning progress tracking
- Resource pages accompanying educational videos
- Community features

## Tech Stack

- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- Passlib
- Uvicorn

## Goals

This project is primarily intended to:

- Strengthen backend engineering skills
- Learn API design and authentication
- Practice database modeling
- Understand application architecture
- Build a foundation for a future educational platform
